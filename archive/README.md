# Archive

Development material kept for reference. None of it is part of the extension that runs in the browser.

| Folder / file | What it is |
|---|---|
| `tests/` | Unit and real-browser test suites. Run from the repo root: `node archive/tests/browser-smoke.js` |
| `docs/` | Product brief, launch readiness, feature inventory, test results, UX audit, roadmap log |
| `design-system.html` | Live samples of the extension's UI tokens and components (open via a local server from the repo root) |
| `DESIGN.md`, `PRODUCT.md` | Design system and product notes |
| `CLAUDE.md`, `AGENTS.md` | Instructions for AI coding agents working on this code. Paths in them are relative to the repo root; tests now live in `archive/tests/` |
| `brand/` | Logo masters (Burst mark, lockups, app icons) |
